# Module 12 — Testing Biases

Review a fictional toy store's Pay Your Age promotion in a 50-minute paired activity inspired by Build-A-Bear's 2018 event. All classroom data are invented. Use simple pandas to check satisfaction, conversion, and changing store mix, then decide what evidence would establish success. Covers selection bias, Simpson's paradox, and confirmation bias through peer review.

## Get started

From Terminal (Mac) or PowerShell (Windows):

```text
cd ~/dso576
git clone https://github.com/USC-DSO-576-YA/12-testing-biases.git
cd 12-testing-biases
```

Open the `12-testing-biases` folder in VS Code. Choose **Terminal → New Terminal** and run:

```text
uv sync
```

Open `promotion_review.ipynb` in VS Code. Use **Select Kernel → Python Environments** and choose this repository's `.venv`. Run cells from top to bottom, discuss each claim, and complete the response cells. Keep the `data` folder beside the notebook.

- `data/survey.csv`: all 30 survey responses, including families who left or were turned away.
- `data/traffic.csv`: family-visit and purchase counts by day and store type.

All data are fictional. Work locally; do not push your answers to the shared repository. Follow your instructor's submission instructions.
